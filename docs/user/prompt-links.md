# Prompt links

A received prompt link opens a prefilled draft for you to review and send.

- With a repository, the draft opens in your most recently used project for that repository. If you do not have the repository, choose **Clone** or **Use without project**.
- With a provider and model you have set up, the draft uses them. T3 Code tells you when it uses your default instead.
- With a pull request, the draft opens in the linked thread. If there is no linked thread, T3 Code asks before checking out the PR branch in a new worktree.
- With a link to an existing thread, T3 Code asks before replacing text in its composer.

T3 Code warns you when it finds hidden characters in a linked prompt and removes them.
