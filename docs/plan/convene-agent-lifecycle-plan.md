## 交付与分支

基于现有 V2，修正“限时探测结果代表整个 Agent 可用性”的设计。正常初始化持续等待，
等待期间取消按钮始终可用；不显示等待较久、百分比、内部探测说明，不自动杀进程重试，
不以旧缓存伪装当前连接成功。分别核实其他 Agent 的实际需要，不统一删除超时。

T3 独立分支 `codex/agent-lifecycle`，平台独立分支 `codex/t3-agent-lifecycle`。
分阶段提交和验收后，分别合回 `codex/convene-integration` 与
`codex/t3code-platform-integration`。不合并 main，不创建上游 PR。
#7230/#7232 是问题来源和行为参考，不直接叠加旧补丁，不引入 #15945 的延长总预算方案。

## 状态合同与资源归属

| 范围 | 权威来源 | 要求 |
| --- | --- | --- |
| 安装、配置、认证 | Driver 检查与原生事件 | 未知不等于未安装／未登录；明确错误立即呈现 |
| 准备与刷新 | managed provider 的异步操作 | 公开进行中、完成、取消、失败；不按启动总时限判失败 |
| 模型、默认名称、技能、命令、用量 | 各自请求及原生事件 | 独立更新，失败不覆盖认证或运行状态 |
| 实际会话 | V2 ProviderSession 与 Adapter | 复用 starting/ready/running/waiting/stopped/error，不另建状态机 |

在 ServerProvider 中明确初始检查、取消和未知安装结果；加入带操作 ID、实例、工作目录的
准备／刷新描述。状态摘要从事实派生，替换超时、错误文案及仅 ready 可用的隐式判断。
后台刷新不使已可用会话失效，默认名称未知仍只显示“默认模型”。

刷新 RPC 启动／复用操作后及时返回，结果走现有 Provider 更新流；取消 RPC 以操作 ID
定位，沿用环境权限。安装更新的内部验证保留等待完成语义。平台 OPTIONS 等协议标识不变。

操作由实例作用域持有，页面或请求结束不取消操作。同实例同范围共享进行中的操作，周期
刷新不堆积。取消结束本轮读取并释放本轮临时进程，不终止已有执行会话。首次准备取消后
本次实例不自动重启；显式重连、修改配置或下次启动再触发；已可用实例取消刷新只结束当轮。
禁用、删除、账号／配置变化沿用实例重建，旧结果不能覆盖新实例。任务启动取消沿用 V2 Stop，
清理本次启动的 MCP 凭证和资源。保留退出后强制清理、远程请求、业务操作期限，不能用它们
推导未安装或认证失效。缓存只保存可复用信息，不恢复活动操作；旧缓存不符合结构则重建，
不迁移会话数据库。不建设进程池或全局常驻预热。

## Driver 决策

| Driver | 当前问题与本轮边界 |
| --- | --- |
| Codex | 10 秒总预算混合握手、账号和辅助信息。拆分核心初始化和辅助读取，同时覆盖原生账号、托管 ChatGPT；正常初始化可等待与取消 |
| Claude | SDK 初始化期限会使结果变 warning 并被选择器排除。接入生命周期，保留默认配置和用量的独立边界 |
| Antigravity | 健康检查超时变全局 error。接入生命周期；保留账号修订、安装所有权，不后台创建认证会话 |
| Grok | 元数据降级已存在，warning 仍可能被 UI 排除。保留降级，纠正可用性；版本读取失败不是未安装，不后台登录／建会话 |
| Pi | RPC 发现失败已保留可用，实际会话处理交互。保留正确流程，检查版本查询、取消与选择器 |
| Muse | 目录失败被当整体失败，协议没有可靠认证信号。分离目录与准备，不凭目录推导登录状态 |
| Cursor | 使用远程 SDK。保留远程请求期限与明确认证错误，目录失败单独处理，不制造本地进程阶段 |
| OpenCode | 复用现有 1.x/2.x owner，区分本地启动和外部服务，分离附属等待，拒绝连接仍是真实错误 |
| ACP Registry | 显式准备／发现可取消，复用 coordinator；后台不扩大到安装、登录或测试会话；管理操作期限保留 |

仅原生支持默认选择的 Driver 提供默认入口；无有效模型选择且目录未完成时展示加载，
不构造模型或认证事实。各 Driver 的必要修改按源码和行为验证，已正确的流程不重写。

## 前后端

引导、设置、模型选择、项目默认模型和会话页共用能力判断。保持输入与已有选择；等待期间
取消始终可达，取消后可重连。缺安装、配置错误或明确认证拒绝提供对应操作；辅助信息失败
不隐藏整个 Agent。实际任务沿用 V2 starting 与停止，不等待所有辅助信息。

平台配置、OPTIONS、启动／读取／取消、完整 Web 消费同一状态。原生平台会话支持范围仍为
Codex 和 Claude。同步共享合同的移动端消费者与相关检查，不将移动实机算本轮已验收。

## 提交与验证

1. 计划和长期维护决策，冻结基线及边界。
2. 共享合同、managed provider、刷新／取消接口及受控生命周期测试。
3. Codex 后逐项适配 Driver，删除被替代的错误判断与重复刷新。
4. T3 与平台界面；两仓库各自提交。
5. 冻结候选，定向测试／类型／lint／构建，合回集成分支，更新本机并记录验收。

必须覆盖旧 10/25/60 秒边界之后成功、一直等待可取消、明确失败、取消后无遗留进程、
重复执行或晚到覆盖；首次／缓存／重启、二进制／账号／项目变化、成功空目录；辅助读取
分别慢或失败；多实例与多页面一致且互不阻塞；V2 启动、续接、停止、审批、历史、MCP
权限、完整 Web。自动化用受控协议、虚拟时钟和事件，不靠长 sleep。

真实验收只用独立测试目录、本机平台和 Luna。不擅自替换付费模型；每个 Agent 分别记录
协议、实际安装／连接、真实推理，缺安装／账号／Luna 支持写明未覆盖。提供真实 UI 截图，
检查窄窗口、长名称、滚动、等待、取消、失败状态与取消入口。

更新前确认无活动任务并做一致备份，选择 .21 后未占用候选版号。清理本轮临时资源，
保留当前安装及本次回滚版本。专项通过不冒充完整发版门禁。
